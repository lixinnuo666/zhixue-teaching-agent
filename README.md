# 智学 · 多模态教学智能体

一个纯前端的教学辅助工具：把讲义截图或文本素材丢进去，自动解析出知识点结构，再基于这些知识点做答疑、出题和学习报告。

**没有任何后端，所有计算都在浏览器里完成**，整个项目就是静态文件。

## 它能做什么

| 模块 | 说明 |
| --- | --- |
| ① 图文解析 | 本地 Canvas 做视觉分析（尺寸 / 主色 / 清晰度 / 倾斜 / 分栏 / 文字区定位），Tesseract.js 做 OCR |
| ② 知识结构 | 知识点思维导图（可按章节 / 类型 / 重要度 / 素材分区），章节大纲，公式符号提取 |
| ③ 知识图谱 | Canvas 力导向关系图，支持拖拽钉住、缩放平移、按分区过滤 |
| ④ 答疑辅导 | RAG 架构问答：本地检索找素材 + 大模型（可选）组织表达，四种讲解方式：直接回答 / 分步讲解 / 举例说明 / 引导启发 |
| ⑤ 练习测评 | 自动从知识点生成选择题，提交后判分并录入错题本 |
| ⑥ 学习报告 | 掌握度雷达图、学习概览统计、错题回顾 |
| ⑦ 个人知识库 | 按学科归档知识点，可导出 Markdown |

## 快速开始

仓库里有两个版本，按需取用：

### 单文件版（推荐给只想用起来的人）

直接下载 `智学-教学智能体-单文件版.html`，**双击用浏览器打开即可**，不需要起服务器、不需要装任何依赖。

> CSS 和 JS 已全部内联，用 esbuild 把 ES Module 打包成了 IIFE。

### 源码版（推荐给要改代码的人）

目录结构：

```
index.html
assets/
├── css/style.css
└── js/
    ├── app.js              主逻辑与事件绑定
    ├── store.js            全局状态
    ├── data/kb.js          个人知识库
    ├── data/samples.js     内置示例素材
    ├── image/imageAnalyzer.js  图像视觉分析
    ├── nlp/classify.js     学科分类
    ├── nlp/tokenize.js     分词 / 向量 / 相似度
    ├── nlp/extract.js      知识点与关系抽取
    ├── nlp/qa.js           答疑（本地检索）
    ├── nlp/llm.js          大模型接入（RAG 生成层）
    ├── nlp/quiz.js         出题与判分
    └── ui/mindmap.js       思维导图布局渲染
tools/
└── llm-proxy.mjs           本地代理，用于解决浏览器跨域限制
```

因为使用了原生 ES Module，**必须通过 HTTP 访问**，直接双击 `index.html` 会被浏览器的 CORS 策略拦住。任选一种方式起个静态服务：

```bash
# Python 3
python -m http.server 8000

# Node
npx serve .
```

然后打开 http://localhost:8000 。

## 大模型接入（可选）

答疑模块采用 **RAG（检索增强生成）** 架构：

- **本地检索引擎负责「找得准」（Retrieval）**：用 TF-IDF + 余弦相似度从你上传的材料里召回最相关的原文片段
- **大模型负责「讲得好」（Generation）**：在给定素材与讲解风格约束下组织答案，并要求它对素材未提及的内容明确声明，抑制幻觉

未配置时，答疑完全由本地规则引擎作答，**功能不受影响**；配置后答案右上角会显示蓝色「大模型生成」标签。

配置步骤见 [《大模型接入操作指南》](./大模型接入操作指南.md)，要点：

- 顶栏点「⚙ 大模型」→ 选服务商（Base URL 与模型名自动填好）→ 粘贴 API Key → 「测试连接」→ 「保存」
- 支持 OpenAI 兼容协议，可切换 DeepSeek / 智谱 GLM / 通义千问 / Moonshot / 硅基流动等任意兼容服务
- **密钥仅保存在你自己浏览器的 localStorage 中**，不进代码、不进仓库、不上传任何服务器
- 若服务商不允许浏览器直连（CORS），可运行 `node tools/llm-proxy.mjs` 起本机代理兜底
- **容错设计**：调用失败或超时会自动降级为本地规则引擎，核心功能零中断

## 关于 OCR

文字识别调用 [Tesseract.js](https://github.com/naptha/tesseract.js)（CDN 引入），**首次点击「识别图中文字」时需要联网**下载中文识别模型（约 15 MB）。

如果下载失败，程序会自动降级，此时可以改用「粘贴文本」手动输入内容，其余功能不受影响。

## 技术说明

- 零构建、零依赖，原生 HTML + CSS + JavaScript
- 图像分析、关系图、思维导图全部基于 Canvas 2D 手绘
- 知识点抽取与答疑的检索层采用规则 + 统计方法（TF-IDF 加权、余弦相似度、Dice 系数）
- 答疑的生成层可选用大模型（OpenAI 兼容协议，用户自带 Key），无 Key 时降级为本地引擎
- 数据只保存在浏览器内存中，刷新页面会重置；大模型配置持久化在 localStorage

## 说明

本项目为纯前端实现，所有解析与计算均在浏览器本地完成，不依赖任何后端服务，便于团队协作与二次开发。
